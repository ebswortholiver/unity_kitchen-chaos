## Project Overview

This project is a game called Kitchen Chaos, It was built using the Unity game engine with a beginner to intermediate tutorial by Code Monkey. I understand all the coding concepts that were used in this game and I have tried to showcase that with comments throughout the code. You can play the game here: [Kitchen Chaos](https://oebsworth.itch.io/unity-kitchen-chaos).

## Tutorial

1. Recipes customers want, show within the top left portion of the screen. 

2. Prepare the correct recipe for the customer.

3. Deliver the plate with the correct recipe to the delivery counter.

## Controls
### Keyboard

WASD - Movement

E - Interact

F - Alt Interact

Esc - Pause

### Controller

Left Stick - Movement

A (Xbox)/ X (PS) - Interact

X (Xbox/ Square (PS) - Alt Interact

Start - Pause

*Controls can be rebound if desired. Along with volume of sound effects and music.*
